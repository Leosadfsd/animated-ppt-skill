# Authoring and quality

Use the user's template/reference before any defaults. With no direction choose a coherent editorial composition suited to the subject, readable typography and a restrained palette. Source/generate complete illustrative assets with available image tools. Keep text and required evidence editable. Never embed the author's private example deck or copyrighted character assets as a reusable template.

Separate four artifacts:

- Storyboard: manuscript passages, slide purpose and screen wording.
- Scene: stable names, complete asset/group boundaries and final frames.
- Motion manifest: beat, entering edge, delay and duration.
- Validation: structural result, rendered result and observed playback scope.

Author the scene in the available presentation library. Exported object names may differ from authoring names: inspect the actual draft. If names are generic, resolve them against geometry/text once and rename deterministically in the authoring workflow; fail on ambiguity. Never bind by the nth image. Create native groups before animation injection; text and its backing paper share one target.

Check fonts on the target device, overflow and contrast at normal presentation size. Preserve original logo/artwork proportions. Speaker notes hold the real narration and source links, not build/debug messages. Do not bake all text into a full-slide image merely to simplify animation.

Use deterministic scripts to generate/adjust layouts and timing; use UI only for important playback checks. After animation injection, do not re-export the deck through an authoring engine without proving it preserves timing. Keep repairs in the source scene/assets, so rebuilding does not restore an old defect.

Portable handoff contains the final PPTX, manuscript or approved notes, storyboard, assets with provenance, scene/build source, motion JSON, environment instructions and validation scope. Discover tool/runtime paths in the recipient's environment. Do not bundle proprietary host libraries, account data or private originals into the public skill repository.
